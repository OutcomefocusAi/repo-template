Why mutant 6 is equivalent: the guard only matters when an openspec-* path is a symlink to a directory. With the guard the path is printed by the 'echo' branch; without it, find (default -P, no -L/-H) does not follow a symlink given as a start point, matches it as -type l and prints the same single path. Both give 'missing' for its files and 'extra' for the link. No test can tell them apart, so the guard stays as a statement of intent for any find that follows start-point links.
